# FarmChain

A decentralized agricultural supply chain platform with quality-based harvest tracking on Stacks blockchain.

## Features

- Harvest production recording and supply chain tracking
- Quality score assessment for crop evaluation
- Supply coordinator management for distribution oversight
- Premium rewards for high-quality agricultural products
- Transparent inventory monitoring across the supply chain

## Smart Contract Functions

### Public Functions
- `establish-supply-chain` - Initialize agricultural platform
- `record-harvest` - Record crop harvest production
- `assess-crop-quality` - Assess quality scores (coordinator only)
- `distribute-harvest-premium` - Distribute harvest and claim premiums

### Read-Only Functions
- `get-farmer-harvest` - Get farmer's harvest production
- `get-supply-stats` - Get platform statistics
- `get-harvest-inventory` - Get total harvest inventory

## Usage

Deploy the contract to create a decentralized agricultural supply chain where farmers can record their harvests and earn quality premiums based on their contribution to the food supply network.
